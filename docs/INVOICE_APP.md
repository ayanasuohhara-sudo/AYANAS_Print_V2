# 請求書作成アプリ Version 1.0

納品書（App 19）を締日・取引先コードで集計し、請求書（App 20）を作成する。

印刷機能は Version 1.0 では未対応。

---

## kintone アプリ構成

| アプリ | App ID | 役割 |
|--------|--------|------|
| 納品管理 | **19** | 納品書データ・請求済フラグ |
| 請求書作成 | **35** | 請求書レコード・請求明細 |

URL: https://o5nppg7kb4ly.cybozu.com/k/35/

App ID は `js/invoice_create.js` の `INVOICE_APP_ID` で定義。

## 納品管理アプリ（App 19）追加フィールド

| フィールドコード | 種類 | ラベル | 備考 |
|------------------|------|--------|------|
| `invoice_flag` | チェックボックス | 請求済 | 選択肢: `請求済` |

## プラグイン設定

請求書作成アプリ（App 35）に AYANAS Print プラグインをインストールする。

納品管理（App 19）への API 更新権限が必要。

## テスト方法

### 事前準備

1. 上記フィールドを両アプリに作成
2. App 35 にプラグインをインストール
3. 納品管理にテストデータを登録
   - 同一 `customer_code`
   - `delivery_date` が締日内
   - `invoice_flag` 未チェック
   - 明細行あり

### 手順

1. 請求書作成アプリで新規レコードを開く
2. **締日** と **取引先コード** を入力
3. 「**請求明細を作成**」ボタンをクリック
4. 確認
   - 請求明細サブテーブルに納品明細が展開される
   - 税抜合計・消費税（10%）・税込合計が設定される
   - 取引先名が自動入力される
5. レコードを **保存**
6. 納品管理アプリで対象納品書を確認
   - `invoice_flag` に「請求済」がチェックされている

### 異常系

| 操作 | 期待結果 |
|------|----------|
| 締日未入力でボタン | エラー「締日を入力してください。」 |
| 取引先コード未入力 | エラー「取引先コードを入力してください。」 |
| 対象納品書なし | エラー「対象の未請求納品書が見つかりません。」 |
| 請求済の納品書のみ | 上記と同様（抽出対象外） |

### 再実行確認

同一納品書が請求済の場合、再度「請求明細を作成」しても抽出されない。

## 税計算

```
税抜合計 = 明細 amount の合計
消費税   = round(税抜合計 × 0.10)
税込合計 = 税抜合計 + 消費税
```

納品書印刷と同じ 10% 計算。
