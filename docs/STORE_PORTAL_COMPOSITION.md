## 2. 画面構成案（PC / iPad）

```text
┌─────────────────────────────────────────────────────────┐
│ 店舗ポータル（A550）              最終更新 HH:MM  [更新] │
├─────────────────────────────────────────────────────────┤
│ 店舗メニュー                                              │
│ A550 の受付〜作業〜納品〜会計。場所=入庫 / 作業=社内作業   │
│ / 完了=仕上げ完了                                         │
│                                                           │
│ ┌ 受付 ─────────┐ ┌ 作業 ──────────────┐                │
│ │ 個人顧客マスタ │ │ 保管場所移動 [34]  │                │
│ │ 受注登録       │ │ 社内作業登録 [84]  │                │
│ └────────────────┘ │ 検品・仕上げ完了   │                │
│                    │        [工程完了]  │                │
│                    └────────────────────┘                │
│ ┌ 納品・在庫 ────┐ ┌ 会計・引き取り ──┐                │
│ │ 納品書作成     │ │ 店舗入金管理     │                │
│ │ 納期・引き取り │ └──────────────────┘                │
│ │ 在庫           │                                      │
│ └────────────────┘                                      │
├─────────────────────────────────────────────────────────┤
│ 本日の店舗状況（受注／本日納期／引き取り待ち／入金／超過） │
│ ※取得失敗は「未取得」（0と誤表示しない）                  │
│ 現在状況（A550・店舗現物の work_status カード）           │
│ 納期（超過／本日／7日／今月）                             │
│ 検索 ＋ 一覧（ステータスはポータルから変更しない）         │
└─────────────────────────────────────────────────────────┘
```

### タッチ操作（iPad）

- メニューボタン最小高さ **52–56px**
- カード・検索も大きめタップ領域（既存 44px 以上を維持・強化）
- グループは幅狭時に縦積み（`max-width: 900px`）
