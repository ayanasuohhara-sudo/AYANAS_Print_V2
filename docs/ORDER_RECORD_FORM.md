# 受注明細（App 16）フォーム表示の調整

詳細・編集・追加画面で **文字を大きく**し、ヘッダー付近の項目を **4列グリッド** で揃えます。

## 登録（App 16 のみ）

1. `order_record_form.js`（JavaScript）
2. `order_record_form.css`（CSS）

順序はどちらでも構いません。既存の `order_customer_search.js` 等と併用できます。

## 内容

- ラベル 15px / 値・入力 17px（明細サブテーブルは 15px）
- **1行5項目** の行を **5列グリッド** で表示（行どうしの縦位置も揃う）
- フォームは **左寄せ・横幅いっぱい**（最大幅の制限なし）
- ラベル 16px / 入力・表示 19px（明細テーブル 16px）
- 明細サブテーブル行は1行全幅

## フォーム設計の前提

kintone のフォーム設定で **通常フィールドは1行に5項目** に揃えてください。  
5項目未満の行があると、右側が空きます。

狭い画面では 4→3→2→1 列に自動で切り替わります。
