## 本番で設定する一覧条件（案A）

### 画面操作（推奨）

1. App16 → 設定 → 一覧 → **顧客別納期スケジュール** を編集
2. **絞り込み**から保管場所ステータス（工場・店舗・外注先・海外）を**すべて削除**
3. 絞り込みに **納品状態** を追加:
   - **未納品** … 含む
   - **納品待ち** … 含む
   - **納品済** … 含めない
   - **未選択（空欄）** … 含む（UI にチェックがあれば ON）
4. **ソート**は変更しない:
   - 第1: 顧客名 昇順
   - 第2: 納期 昇順
5. 保存（この時点ではまだアプリ更新前でも可。JS とまとめて更新推奨）

### クエリ相当（確認用）

ラベル形式:

```text
delivery_status in ("未納品", "納品待ち", "")
```

フィールド ID 形式（export 互換）:

```text
f5520750 in ("5520749", "5520747", "")
```

※ ドロップダウンは `!=` 不可。空欄は `in ("")` または「未選択を含む」。

| 選択肢 ID | ラベル |
|-----------|--------|
| 5520749 | 未納品 |
