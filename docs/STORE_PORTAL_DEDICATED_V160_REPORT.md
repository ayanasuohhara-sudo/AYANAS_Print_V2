## 2. 実装済み機能（本ターン差分含む）

### 店舗メニュー（業務順）

| グループ | リンク | App |
|----------|--------|-----|
| 受付・顧客 | 個人顧客管理／**受注登録**／**受注検索** | 96 / 16 / **88** |
| 作業・移動 | 保管場所移動／社内作業登録／仕上げ完了 | 34 / 84 / 30 |
| 納品・会計 | 納品書作成／**納期・引き取り待ち管理**／**入金登録** | 19 / 92 / 97 |

- 強調（`featured`）: 受注登録・受注検索・引き取り・入金
- App85 なし
- 権限注記: メニュー表示≠ACL。権限のないユーザーには操作不可と明示

### ダッシュボード（A550）

| 指標 | 定義 | 失敗時 |
|------|------|--------|
| 本日のA550受注件数 | App16 `customer_code=A550` ∧ `order_date=今日(JST)`・取消除外・管理番号ユニーク | **—** +「取得失敗」 |
| 本日納期件数 | A550・店舗現物在庫の `deadline=今日` | 同上 |
| 引き取り待ち件数 | 店舗在庫かつ `引き取り待ち`／`納品待ち`（App92 互換） | 同上 |
| 本日の店舗入金額 | App97 当日・有効・入金の金額合計 | 同上 |
| 納期超過件数 | 店舗在庫の納期超過 | 同上 |

成功時の **0 は 0**（失敗と混同しない）。法人コードは店舗 KPI／在庫に混入させない。

### 工場ポータル維持

- App86: 3ショートカット＋工場サマリ
- 工場クエリに A550 条件なし
- 店舗メニューは工場モードで非表示

### 見た目の区別

- 店舗: 緑系トーン＋バッジ「店舗 A550」
- 工場: 青系トーン＋バッジ「工場」

| 方式 | 採用 |
