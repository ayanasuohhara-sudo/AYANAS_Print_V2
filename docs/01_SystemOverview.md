# AYANAS 基幹システム Version 1.0 — システム全体概要

## 1. 目的

AYANAS 基幹システムは、着物加工業務における **受注 → 納品 → 請求 → 入金 → 売掛** を kintone 上で一貫管理するシステムです。

- 帳票印刷（AYANAS Print プラグイン）と業務アプリを統合
- データの更新元を明確にし、二重管理を防止
- 請求・入金・売掛は共通ルール（`invoice_no` 中心）で連携

## 2. システム構成

| レイヤ | 内容 |
|--------|------|
| 基盤 | kintone（サイボウズ） |
| 拡張 | AYANAS Print V2 プラグイン（JavaScript / CSS） |
| データ | 各業務アプリ（App 16〜38） |

## 3. 業務フロー

```
受注
  ↓  受注明細アプリ（App 16）で受注登録・加工管理
納品
  ↓  納品管理アプリ（App 19）で納品書作成
請求
  ↓  請求書作成アプリ（App 35）で請求書作成・確定
入金
  ↓  入金管理アプリ（App 36）で入金登録
売掛
  ↓  売掛一覧アプリ（App 37）で残高確認
完了
     売掛残高 = 0（回収済）
```

### 3.1 請求サブフロー（詳細）

```
未請求納品書（invoice_status = 未請求）
  ↓ 未請求データ取込 / 請求書一括作成
請求書（invoice_status = 作成中）
  ↓ 請求確定
納品書（invoice_status = 請求済）＋ 請求書（invoice_status = 確定）
  ↓ 請求書印刷
入金登録 → 請求書へ累計入金反映
  ↓
売掛一覧でモニタリング
```

## 4. 設計原則（Version 1.0）

| 原則 | 内容 |
|------|------|
| 単一更新源 | 請求金額＝請求書、入金額＝入金管理、納品請求状態＝納品管理 |
| 計算値の同期 | 売掛残高は `total − payment_amount` を請求書に保持 |
| 読取専用ビュー | 売掛一覧（App 37）は更新しない |
| 権限 | kintone アクセス権 + プラグインによる業務ルール（作成中のみ編集等） |
| 監査 | 請求締め実行履歴（App 38）に一括処理を記録 |

## 5. プラグイン概要

**AYANAS Print V2**（`manifest.json`）

- 受注票・納品書の印刷（完成）
- 請求書作成・入金・売掛連携（開発中〜V1.0 実装済みモジュールあり）
- 請求書印刷テンプレート（予定）
