## 特に確認した論点

1. **App13中分類:** `item_code`→`subcategory` で海外/国内判定可。ヘッダー subcategory 不使用。  
2. **追加加工:** 直近300件中111件が複数中分類、71件が海外＋他加工。枚数の優先順（海外→国内/帯→悉皆）は妥当。金額を着物区分へ丸ごと寄せると追加加工が混入。  
3. **App16:** order_date / customer_code / detail amount・qty は集計に使用中。取消は0件。  
4. **国内ルート別:** 27（外注先コードあり）/ 74（和裁士）で件数分離可。仕立×ルート結合UIなし。  
5. **海外原価:** App28に原価なし → システム内取得不可。  
6. **受注日≠納品日:** 定義分離済み。経営報告では軸明示が必要。  
7. **A550:** `customer_code=A550` のみ店舗。App8部門は未使用。  
8. **ラベル不一致:** 本番「洗張り」「修理」 vs 設定「洗い張り」「修理・直し」「汗抜き」→ 悉皆が「その他」化しやすい。
