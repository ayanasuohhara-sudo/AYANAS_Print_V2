# 和裁士別仕事予定カレンダー — ホスト App セットアップ

**本番反映は別途承認後。** 第1段階 JS はリポジトリに用意済み。

---

## 1. ホスト App 作成

1. kintone でアプリを新規作成  
2. 推奨アプリ名: **和裁士別仕事予定カレンダー**  
3. フォームは最小でよい（スペース1つだけ等）。一覧をカレンダー UI が隠す  
4. 作成後の **App ID** を控える  

空き ID 例（2026-11-14 時点で未使用）: 98 以降。採番は環境に任せる。

---

## 2. 設定変更（デプロイ直前）

`customize/wasai_schedule_config.js`:

```javascript
HOST_APP_ID: <作成したAppID>,
```

一時検証のみ:

```javascript
window.CAYANAS_WASAI_SCHEDULE_HOST_APP_ID = <AppID>;
```

## 6. 第2段階 — App73 `monthly_capacity`（本番は別承認）

フォームに数値フィールドを追加（**既存5件は空＝未設定のまま。データ破壊なし**）:

| 項目 | 値 |
|------|-----|
| フィールド名 | 月間処理可能枚数 |
| コード | `monthly_capacity` |
| タイプ | 数値 |
| 必須 | いいえ |
| 小数部 | 0（整数） |
| 最小値 | 0（設定可能な場合） |

カレンダーは空を「未設定」、`0` を「0枚」と区別表示する。  
変更は App73 レコード編集のみ。ホスト App から書き込まない。

JS デプロイ順: **先に App73 フィールド追加 → ホスト JS 登録**（未追加でも GET フォールバックで「未設定」表示可）。
