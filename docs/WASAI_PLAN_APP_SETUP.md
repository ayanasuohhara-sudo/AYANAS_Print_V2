# 和裁士仕事予定管理 App — 設計（第3段階・本番未作成）

**本番の新規 App 作成・反映は別途承認後。** 本ドキュメントと JS はローカル実装。

推奨アプリ名: **和裁士仕事予定管理**  
ホスト（App98）から参照。`PLAN_APP_ID` に採番後の ID を設定する。

---

## 2. 二重計上防止

1. カレンダー集計の正本は **App74 出庫確定明細**  
2. 予定側で `plan_status = 予約` かつ `manage_no` が App74 出庫確定に存在する → **表示・枚数から除外**（出庫側に一本化）  
3. 明示リンク時は `plan_status = 出庫済` と linked_* を保存（同期ジョブ／保存時）  
4. `取消` は常に非表示・非集計  

---

## 3. 管理番号の重複対策

- 同一 `wasai_code` + 同一 `manage_no`（空でない）で `plan_status = 予約` が2件以上あることを禁止  
- 保存前に予定 App を検索し、衝突があればエラー  
- 枠予定（`manage_no` 空）は複数可  

---
