## 1. 税計算確認結果

| 項目 | 結果 | 根拠 |
|------|------|------|
| App16 金額が税抜 | **一致** | `detail_table.amount` = CALC `unit_price*qty`。税フィールドなし（本番フィールド確認） |
| 税率 10% の適用範囲 | **受注（App16 1 レコード）単位**で `Σ amount` に対し 1 回 | `getOrderBilledInclusive` |
| 端数 | **`Math.round(ex × 0.1)`** | 印刷 `js/core.js` / 納品テンプレと同型 |
| App19 CALC | `tax = subtotal*0.1`（端数関数なし） | S1 は印刷同型の round を採用（意図的） |
| スマレジ `taxRounding` | **実機未確認**（リポジトリからは不可） | 残存リスク §6 |
| 複数商品（同一受注内明細） | 明細合計を税抜として 1 回課税 | 実測例: 3150+1500 → 税込 5115 |
| 複数受注一括会計 | **受注ごとに税込を算出し合算** | カート一括丸めと **±1 円差**があり得る（単体で `[5,5]` → 12 vs 11 を確認） |
| 税率 8% / 非課税 | **未対応** | App16・App13 に税率区分フィールドなし。現状データも 10% 前提の単価運用 |

### 判定

- **単品（1 manage_no）・10% のみ**: 印刷と一致。限定 E2E 可。
- **複数 manage_no 一括**: S1 合計とスマレジカート税込が **1 円ずれる場合あり**。日次照合・手入力で検知。
- **8% / 非課税商品が出た場合**: **本番一般公開を停止**し仕様追加が必要。

→ 金額不一致を「全面ブロッカー」とはしないが、**スマレジ実機の税丸め確認と、複数商品 E2E での 1 円差観測を検証フェーズ必須**とする。

## 2. 入金・引き取りの安全性

| 要件 | 方式 | 判定 |
|------|------|------|
| 同一バーコード 2 回読取で二重入金しない | UI `busy` / 同一 `transaction_id` 冪等 / 残額 0 は選択不可 / POST 前残額再取得 | **OK** |
| 複数端末同時でも過剰入金しない | POST 前残額再検証 + **POST 後 `detectOverAllocation` → 自動取消**（v1.1.1）+ `transaction_id` unique | **OK（強化済）** ※完全直列化ではないが過剰は残らない |
| 入金失敗時に納品済にしない | `registerPayment` は App16 を更新しない。引き取りは別 API | **OK** |
| 入金成功・App16 失敗の復旧 | 入金レコードは残る。UI「引き取り完了」再実行。既に納品済なら `alreadyDone` | **OK** |
| 一部入金は原則引き取り不可 | `canPickupWithBalance`。例外は `unpaid_handover_approved` のみ | **OK** |
| 選択商品だけ納品済 | `completePickup(orderRecordId)` を選択行ごと。他行は不変 | **OK** |
| 返金・取消の履歴 | 取消=同一レコードを `payment_status=取消`（物理削除しない）。返金=マイナス別レコード + `related_refund_of` 必須 | **OK** |

### 同時入金防止方式（要約）

1. クライアント: 送信中ロック、固定 `transaction_id`
2. サーバ制約: `transaction_id` / `store_payment_no` **unique**
3. 業務: 保存直前に S1 有効充当を再集計し残額超過を拒否
4. 競合後処理: POST 成功直後に過剰なら **当該入金を自動取消**してエラー返却（App16 非更新）

### 障害時の復旧方法

| 障害 | 復旧 |
|------|------|
| 入金 POST 失敗 | 再実行。App16 変化なし |
| 入金成功・画面エラー | 入金番号で App97 を確認。重複なら冪等 |
| 入金成功・引き取り PUT 失敗 | App97 入金は有効のまま。対象 manage_no を選び「引き取り完了」再実行 |
| 自動取消された競合入金 | 取消理由に「過剰充当」と記録。再読込して残額どおり再登録 |
| 誤入金 | `payment_status=取消` + 理由。必要なら返金レコード |
| 誤って納品済 | S1 では自動戻ししない。権限者の App16 手修正（別承認運用） |
