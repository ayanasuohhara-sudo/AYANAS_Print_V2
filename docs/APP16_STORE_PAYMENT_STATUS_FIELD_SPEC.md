# App16 入金状況フィールド仕様（本番反映は別承認）

## 追加フィールド

| コード | ラベル | 型 | 必須 | 初期値 | 選択肢 |
|--------|--------|-----|------|--------|--------|
| `store_payment_status` | 入金状況 | DROP_DOWN | なし | `未入金` | `未入金` / `一部入金` / `入金済み` |

## 対象

- **A550（店舗）受注のみ**運用対象
- 法人顧客レコードでは空／非表示・編集不可（JS で制御）
- App21 / App35 には追加しない

## 配置

- 店舗向けに視認しやすい位置（お客様名・納品状態の近く）
- 一覧ビューに列として追加し、絞り込み可能にする

## 変更履歴

- kintone 標準のレコード変更履歴で確認可能（追加フィールド不要）
- 納品済レコードの変更は一覧 UI で確認ダイアログを表示

## 注意

- 既存フィールドの削除・型変更なし
- 過去レコードの一括 PUT は **別承認後**（調査スクリプトのみ先行）
- 金額・入金日はスマレジ正本。本フィールドは状況ラベルのみ
