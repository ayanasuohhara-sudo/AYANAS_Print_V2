## 2. 「少なく見える」理由の詳細

### A. UI上の表示単位（最有力）

- **得意先ランキング** = 選択月の `byCustomer` のみ（`buildCustomerRanking`）
- **得意先マトリクス** = 年度内 ready 月の合計（`yearTotal`）

そのため、画面でランキングの **17** だけを見ると、実在の年度合計 **132** や通算仕立て **251** より少なく感じる。

### B. 仕立て定義による除外（仕様）

中分類が次のいずれかでない受注は枚数に入れない。

- 海外仕立 / 国内仕立 / 帯仕立

other の例（M032）: 修理・丸洗い・ガード・クレームのみ、返品 など。  
2026年度 other **20件**、2025年度 ready 期間 other **31件**。

### C. 品名「海外仕立て」の未解決（軽微・最大6件）

明細品名が **「海外仕立て」**（「て」付き）の行は App13 にヒットせず `(未解決)`。  
他に仕立中分類が無い受注は route=`other` となり、**6件**が仕立て未算入。

例: `050726-14`, `050826-07` など（2026-05）。

仮説: エイリアス `海外仕立て → 海外仕立` を足すと仕立ては 251→**257**（+6）。欠落の主因ではない。

App13 側の正規名は主に `仕立`（中分類 `海外仕立`）など。「海外仕立て」という品名そのものはマスタに無い。
