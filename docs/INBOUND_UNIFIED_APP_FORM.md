# 統合「入庫管理アプリ」フォーム設計案

**Version**: 0.3（フォーム確定・JS 未実装）  
**前提**: App 16 / 27 / 28 / 29 / 32 の既存 ZIP・カスタマイズ JS 調査結果  
**方針**: App **29・32 は新規入庫入力を止め**、本アプリに集約。29/32 は**過去データ参照のみ**残す。

---

## 画面イメージ（操作）

1. **新規作成** → ヘッダー `inbound_date`（既定：当日）・状態「下書き」
2. **バーコード連続読取** → 都度 **入庫明細** 行を追加（App 16 特定・27/28 判定・マスタ情報自動セット）
3. 明細一覧で **待機 / エラー** を確認。**エラー行が1件でもあれば一括入庫不可**
4. エラー行を削除するか原因解消後、**全行が「待機」** になってから **一括入庫**（**全件成功方式**）
5. 一括入庫 → 行ごとに App16・出庫元更新成功時点で行「確定成功」→ **全行成功**でヘッダー「入庫確定」
6. 確定後は **編集不可**（履歴として保存）

### 確定事項（2026-03）

- App 27 `outsource_detail.line_in_date` を追加し、**明細行単位**で入庫状態を管理（部分入庫あり）
- 一括入庫は **全件成功方式**（エラー1件でも実行しない）
- 途中 API 失敗時は **同レコードで補完再実行**（全 PUT のやり直し禁止）。詳細は `INBOUND_UNIFIED_APP_SETUP.md` **§7.4〜7.6**
- B16 `scheduled_return_date` / B17 `scheduled_arrival_date` は **別フィールドのまま**
- `inbound_route` は **完全自動**（ユーザー選択なし）
- App 29・32 は **過去履歴のみ**（新規入庫に不使用）

## 入庫区分自動判定（確定ルール）

```
1. App 16 に manage_no が存在しない → エラー（受注なし）
2. App 28 で overseas_in_date 空の出庫レコードに manage_no（または overseas_manage_no / overseas_details）一致
   → inbound_route = 海外外注
3. 2 に該当せず、App 27 の outsource_detail に manage_no 一致
   かつ App 16 が process_status=外注中 AND location_status=外注先
   → inbound_route = 国内外注
4. App 16 が 海外外注中+海外 だが 2 なし → エラー（出庫記録なし）※運用で 16 のみ救済するかはポリシー
5. 既に入庫済み → エラー（二重入庫）
6. 同一ヘッダー内の duplicate manage_no → エラー（連続読取の重複）
```

## JS 実装条件 — 途中失敗後の補完再実行（確定）

フォーム項目の追加は **行わない**。既存の `inbound_batch_no`・`inbound_remarks`・明細スナップショットで足りる。

| 要件 | 内容 |
|------|------|
| 禁止 | 途中失敗後、**全明細を未処理として最初から PUT し直す** だけの再実行 |
| 必須 | 再実行前に **App 16 / 27 / 28 / 74 / 入庫管理行** を **再 GET**（**`確定成功` 行も含む**） |
| 必須 | **目標状態（`inbound_date` = D）** と照合し、**達成済みの PUT はスキップ** |
| 必須 | **`待機` 行**は途中反映を含め **不足分のみ** 補完。**`確定成功` 行**は整合確認し問題なければスキップ |
| 必須 | **行ごとに** 出庫元＋App16 が目標どおりになった時点で **`line_result=確定成功`・`applied_at`**（途中失敗しても **成功行を待機に戻さない**） |
| 必須 | **全行 `確定成功`** のときのみヘッダー **`inbound_status=入庫確定`** |
| 区分 | **通常の二重入庫** と **途中失敗の一部更新済み** を **別ロジック** |
| 識別 | **`inbound_batch_no`** を初回一括入庫前に発行し、**同一レコード再実行時は維持**。`inbound_remarks` に **attempt ログ** |

詳細アルゴリズム・エラー区分表: **[INBOUND_UNIFIED_APP_SETUP.md §7.4〜7.6](./INBOUND_UNIFIED_APP_SETUP.md)**
