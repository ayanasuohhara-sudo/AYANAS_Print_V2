# App16 フィールド追加仕様（本番反映は別承認）

## 追加フィールド

| コード | ラベル | 型 | 必須 | 選択肢 |
|--------|--------|-----|------|--------|
| `client_name_kana` | お客様名ふりがな | 文字列（1行） | なし | — |
| `client_name_kana_status` | ふりがな確認状態 | ドロップダウン | なし | `未確認` / `確認済` / `不明` |

## 配置

- `client_name`（お客様名）の近く
- 空白スペース `client_kana_space` を追加すると登録UIがそこにマウントされる（無ければヘッダーメニュー領域）

## 注意

- 既存フィールドの削除・型変更なし
- 過去レコードは空のまま（一括PUTしない）
- App8 / App96 は変更しない
