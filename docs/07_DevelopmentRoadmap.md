# AYANAS 基幹システム Version 1.0 — 開発ロードマップ

## 開発方針（必須）

**新しい機能は追加しない。まず Version 1.0 を完成させる。**

### 開発フロー

```
仕様決定 → 実装 → テスト → 修正 → 完成
```

| 原則 | 内容 |
|------|------|
| 仕様先行 | 設計変更は **必ず事前に提案** し、合意後に着手する |
| 後方互換 | **既存機能を壊さない** ことを最優先する |
| コミット | 完成した機能は Git へコミットする |
| タグ | 重要な区切りでタグを付ける（下記参照） |

### リリースタグ

| タグ | 内容 | 状態 |
|------|------|------|
| `v1.0` | 受注票 | 完成 |
| `v2.0` | 納品書 | 完成 |
| `v3.0` | 請求書 | **開発中** |
| `v4.0` | 入金管理 | 未着手 |
| `v5.0` | 売掛管理 | 未着手 |

※ Version 1.0 完成 = `v5.0` まで到達した時点。

### Version 1.0 スコープ外（着手禁止）

以下は設計のみ保持し、**V1.0 完成後** に検討する。

- 監査ログ（App 39）— [09_AuditLog.md](./09_AuditLog.md) 参照
- 国内仕立外注 / 国内仕立支払
- WEB予定管理 / 店舗POS連携
- 銀行 API / 通帳取込 / メール送付 等
