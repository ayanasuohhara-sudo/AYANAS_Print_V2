# 受注明細（App 16）顧客名検索

## 概要

`order_customer_search.js` は、受注明細の新規作成・編集画面に **顧客名の部分一致検索** を追加します。

従来の **顧客コードルックアップ** に加え、顧客名の一部（例: `山田`）で顧客管理から検索し、選択すると `customer_code` / `customer_name` に反映されます。

## kintone への登録

1. kintone 管理画面 → App **16（受注明細）** → 設定 → JavaScript / CSS でカスタマイズ
2. `order_customer_search.js` をアップロード
3. 保存 → アプリを更新

## 設定

| 定数 | デフォルト | 説明 |
|------|-----------|------|
| `ORDER_APP_ID` | 16 | 受注明細 |
| `CUSTOMER_APP_ID` | 8 | 顧客マスタ |

## 検索仕様

- 顧客名・顧客コードの **部分一致**
- `株式会社` `有限会社` `（株）` などは **検索語から自動除去**
- 候補は最大 20 件
- 候補クリック、または Enter で 1 件のみヒット時に自動反映

## 設置位置

1. **推奨:** フォームに空白スペース `customer_search_space` を追加 → その中に検索 UI を表示
2. **未設定時:** `customer_code` フィールドの直前に自動挿入

## 一覧画面の顧客コード検索について

一覧の絞り込み（`schedule_customer.js` 等）は別ファイルです。一覧にも顧客名検索が必要な場合は別途対応してください。
